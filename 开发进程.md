## 2026-08-02 18:05 — 修复：拖动/缩放地图时散点脱离地图、缩放跳动

| 项目   | 详情                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 症状   | 手机端拖动/捏合地图时：大小变化异常（跳动）、红点脱离地图被拖动                                                                                                                                                                                                                                                                                                                                                                 |
| 根因   | 两个叠加问题：① 地图 canvas `touch-action:auto`，手机浏览器可抢走双指手势做页面缩放，与 ECharts 地图缩放叠加/冲突（ECharts 自身不设置 touch-action）；② 原实现用 rAF 在 roam 事件流中实时调 `chart.setOption` 切换城市标注——roam 途中 setOption 重绘与手势状态竞争，散点层与地图层失步（已知问题类别，参考 apache/echarts issue 8890 等）                                                                                          |
| 修复   | ① CSS 新增 `#map canvas{ touch-action:none; }`，手势完全交给 ECharts；② 标注更新改为「手势结束后执行」：georoam 仅设 200ms 尾随定时器；touchstart/mousedown 时取消挂起更新，touchend/touchcancel/mouseup 时立即刷新——拖动/捏合全程绝不调 setOption                                                                                                                                                                          |
| 验证   | 滚轮缩放 3.22 倍后标注自动显示、zoom 不再回跳；缩小回 0.52 倍标注自动隐藏；拖拽平移后散点零漂移（逐点对比 itemLayout 与 convertToPixel）；点击名单城市 → 提示框正常；手机端地图正常显示、无横向溢出；控制台无报错。注：无头环境无法模拟双指捏合（CDP 触摸事件被浏览器/zrender 吞掉），捏合路径按上述机制修复，建议真机复核                                                                                                   |

## 2026-08-02 17:52 — 修复：手机端地图完全不显示（v1.1 回归）

| 项目   | 详情                                                                                                                                                                                                                                                                                                                                              |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 症状   | 手机端（≤720px）地图区域完全空白；桌面端正常                                                                                                                                                                                                                                                                                                     |
| 根因   | 三层叠加：① `main` 是高度受限的 flex 列容器（`body height:100%` 链路）；② v1.1 将手机端 `#list` 改为 `max-height:none` 整页滚动后名单高达 2000px+ 且 `flex-shrink:0` 不可收缩；③ `#map-box` 仍为 `flex:1`（`basis:0%, shrink:1`），负空间全部分摊到它 → 高度塌缩为 0；叠加 v1.1 新增的 `overflow:hidden`，把 439px 高的地图画布完全裁掉 |
| 修复   | 手机端媒体查询中加 `#map-box{ flex:none; }`，让地图容器按内容（52vh）自适应高度、不参与收缩；名单自然下排、随整页滚动                                                                                                                                                                                                                             |

## 2026-08-02 17:16 — 15班班级蹭饭地图 v1.1 更新

| 项目     | 详情                                                                                                                                                                                                                                     |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 任务     | v1.1：手机查看优化 + 地图文字自适应显隐                                                                                                                                                                                                  |
| 优化①    | 地图标注自适应：显示范围广（缩到最小/全国概览）时只显示点位、不显示城市名；放大到标注不重叠时自动显示「城市名 + 人数」。基于像素碰撞检测（`convertToPixel` 计算各标记屏幕坐标，纵/横向重叠判定）+ 缩放阈值 1.25 倍，拖动、缩放、窗口变化时实时重算 |
| 优化②    | 地图左上角新增提示条「🔍 滚动 / 双指缩放地图，放大后显示城市标注」，标注显示后自动淡出、缩小后重新出现                                                                                                                                    |
| 优化③    | 手机端（≤720px）适配：徽章/标题/教师条/统计条紧凑排版，地图高度 52vh，名单改为随整页滚动（移除内嵌滚动条），城市条目加大点击区域，禁用双击缩放延迟（`touch-action:manipulation`）、去除点按高亮闪烁                                                                 |
| 优化④    | tooltip 适配：`confine:true` 限制提示框不超出地图边界；内容限高 220px 内部滚动（北京 8 所学校不再撑出 2000px+ 长条）；`#map-box overflow:hidden` 兜底防任何浮层横向溢出；窗口变化时先收起提示框、重绘后延时再收一次（避免 setOption 重绘重新唤起提示框造成旧坐标残留） |

### 验证记录（Playwright，真实输入事件）

- 桌面端（1280×800）：概览仅点位、无横向溢出；真实滚轮放大 → 城市标注自动出现、提示条淡出；缩回 → 标注隐藏、提示条回归；点击成都标记 → 名单定位闪烁；统计条 54 人 / 38 校 / 19 城正确
- 手机端（390×844）：单列布局、无横向溢出，地图 52vh + 名单整页滚动；点名单城市 → 提示框显示且不超视口（242px 高）；带着打开的提示框旋转屏幕 → 提示框自动收起、全程无横向溢出
- 踩坑记录：ECharts 5.5.1 读取缩放需用 `coordinateSystem.getZoom()`（`.zoom` 属性不可用）；`geoRoam` 动作需带 `originX/originY` 才生效；合成 WheelEvent 不触发 roam（zrender 过滤），验证需真实输入事件

## 2026-08-02 15:50 — 创建 15班班级蹭饭地图 v1.0
