## 2026-08-02 19:12 — 修复：红点层与地图层整体错位（手势中 setOption）+ 加载时圆点冻结消失

| 项目   | 详情                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 症状   | 用户反馈"所有红点点层和地图层错位"                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 根因①  | **ECharts 地图手势（拖拽/捏合）进行中调 `chart.setOption` → 地图层与模型投影失步**：已用像素级检测复现（拖拽中途 setOption 后 19 城中 13 城投影点落在画布空白处），错位状态不随继续拖拽/滚轮缩放自愈，只有全量重绘（`chart.resize()`）能恢复。我们代码里 3 条路径可能在手势中触发 setOption：① georoam 200ms 尾随定时器——捏合中途停顿（手指未抬）照常触发；② touchend 立即刷新——捏合中抬起一指即触发；③ resize 后的定时器调度 |
| 根因②  | **加载瞬间的 `updateMapLabels()` 触发 setOption，打断散点进场动画**：部分圆点（实测移动端 9 个城市）被冻结在 scale≈0 直接消失/残缺；已定位为 `labelOn` 初始值 true 导致加载即 setOption |
| 修复   | ① **手势守卫**：新增 `activeTouches`（多指计数）+ `mouseDown` + `gestureActive()`；georoam 定时器在手势中自动续延、`touchend` 仅在全部触点抬起后刷新、resize 调度在手势中推迟——**手势进行中绝不调 setOption**；② **移除 `zlevel:2`** 散点与地图合并单画布，消除"图层冻结"类错位的结构根因；③ `labelOn` 初始置 `false`，加载后首次标注计算直接早退，进场动画不被中断 |
| 验证   | 5 视口（390×844 / 768×1024 / 844×390 横屏 / 960×700 / 1280×800）：初始 19/19 圆点完整、地图-模型轮廓命中率 74%± 一致（对齐基线）；拖拽（中途停顿 300ms）+ 缩放 + 缩回全程零错位、零丢点；标注随缩放正常切换（3.22 倍显示、缩回 0.75 隐藏）；守卫验证：按住 500ms 期间 setOption 零调用、双指抬起一指计数正确且刷新被阻止；控制台零错误 |

## 2026-08-02 18:05 — 修复：拖动/缩放地图时散点脱离地图、缩放跳动

| 项目   | 详情                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 症状   | 手机端拖动/捏合地图时：大小变化异常（跳动）、红点脱离地图被拖动                                                                                                                                                                                                                                                                                                                                                                 |
| 根因   | 两个叠加问题：① 地图 canvas `touch-action:auto`，手机浏览器可抢走双指手势做页面缩放，与 ECharts 地图缩放叠加/冲突（ECharts 自身不设置 touch-action）；② 原实现用 rAF 在 roam 事件流中实时调 `chart.setOption` 切换城市标注——roam 途中 setOption 重绘与手势状态竞争，散点层与地图层失步（已知问题类别，参考 apache/echarts issue 8890 等）                                                                                          |
| 修复   | ① CSS 新增 `#map canvas{ touch-action:none; }`，手势完全交给 ECharts；② 标注更新改为「手势结束后执行」：georoam 仅设 200ms 尾随定时器；touchstart/mousedown 时取消挂起更新，touchend/touchcancel/mouseup 时立即刷新——拖动/捏合全程绝不调 setOption                                                                                                                                                                          |
| 验证   | 滚轮缩放 3.22 倍后标注自动显示、zoom 不再回跳；缩小回 0.52 倍标注自动隐藏；拖拽平移后散点零漂移（逐点对比 itemLayout 与 convertToPixel）；点击名单城市 → 提示框正常；手机端地图正常显示、无横向溢出；控制台无报错。注：无头环境无法模拟双指捏合（CDP 触摸事件被浏览器/zrender 吞掉），捏合路径按上述机制修复，建议真机复核                                                                                                   |
